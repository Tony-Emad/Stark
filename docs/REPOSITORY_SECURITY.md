# Repository security and ownership

Owner: Tony Emad  
Copyright: © 2026 Tony Emad. All rights reserved.

Stark's repository is public, so GitHub cannot technically prevent another
person from reading or copying public files. Public visibility does not
transfer copyright or authorship. The repository's proprietary license,
copyright notice, `NOTICE`, and `OWNERSHIP.md` preserve Tony Emad's ownership
and restrict redistribution.

The `main` branch is protected on GitHub. Changes must be submitted through a
Pull Request; direct pushes are rejected. No passwords, Keychain data, camera
frames, signing certificates, or notarization credentials belong in Git.

Local source files remain writable by the owner so the project can be built
and maintained. GitHub branch protection is the meaningful control for a
public repository; filesystem read-only flags would not protect a public copy
or a fork.
